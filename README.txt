GOSSIP — бесплатный вариант для публикации в интернете

ВАРИАНТ: Cloudflare Pages + Cloudflare D1
Для небольшого тестового сайта можно начать на бесплатных тарифах. Платёжные данные не нужны для обычного старта, но проверяй выбранный тариф и не подключай платные дополнения.

ЧТО НУЖНО
- Аккаунт Cloudflare (бесплатный)
- Аккаунт GitHub (бесплатный)
- Компьютер, чтобы загрузить файлы проекта в GitHub

ШАГ 1 — ЗАГРУЗИ ПРОЕКТ В GITHUB
1. Скачай и распакуй ZIP.
2. Создай репозиторий на https://github.com/new
3. Загрузи в него все файлы и папки из архива (в том числе functions, migrations, public и wrangler.toml).

ШАГ 2 — СОЗДАЙ БАЗУ ДАННЫХ D1
1. Войди на https://dash.cloudflare.com/
2. Открой Workers & Pages → D1 SQL Database (название раздела может немного отличаться).
3. Создай базу с именем gossip-db.
4. Скопируй Database ID созданной базы.
5. В файле wrangler.toml замени REPLACE_WITH_YOUR_D1_DATABASE_ID на этот ID и сохрани изменение в GitHub.
6. В базе открой SQL Console и выполни весь текст из migrations/0001_create_stories.sql.

ШАГ 3 — ОПУБЛИКУЙ САЙТ
1. В Cloudflare открой Workers & Pages → Create → Pages → Connect to Git.
2. Подключи GitHub и выбери репозиторий gossip-anonymous.
3. Framework preset: None. Build command оставь пустой. Build output directory: public.
4. Создай проект и дождись публикации.
5. Cloudflare выдаст адрес вида https://название.pages.dev

ШАГ 4 — ПРОВЕРЬ
Открой выданную ссылку. Опубликуй тестовую историю, затем открой сайт в другом браузере/на телефоне — история должна появиться и там.

ВАЖНО
- Не покупай домен: бесплатного адреса pages.dev достаточно.
- Не подключай платные функции и тарифы; проверяй экран оплаты перед подтверждением.
- Бесплатные тарифы имеют ограничения, которые провайдер может менять.
- Этот проект не требует платного Node.js-сервера: страницы работают на Pages Functions, истории хранятся в D1.
- Жалобы скрывают запись после трёх жалоб, но это базовая защита, не полноценная модерация. Для открытого публичного сайта желательно добавить админ-панель и более сильную антиспам-защиту.
- Приложение не просит имя и аккаунт. IP-адрес используется только для краткого ограничения частоты и сохраняется в базе в виде хеша; это не обещание абсолютной анонимности.
